# LifeOS · 模块白板 MVP

一个本地白板，每个模块拥有自己的记录集合和属性。可自由添加每日记录、健康、购物、计划或自定义模块。

## 启动

需要 Python 3.10 或更新版本。网页主体只使用 Python 标准库。在本目录运行：

```sh
python3 app.py
```

也可以在终端运行 `./启动LifeOS.sh`。浏览器打开 http://127.0.0.1:8765 。保持程序运行；Ctrl+C 停止。

指定资料目录：`python3 app.py --data-dir /你的资料目录`。第一次运行会从已有 `records.json` 迁移；原始文件另存到 `data/backups/migration-*.json`。已有 SQLite 时只读取 SQLite，不会用 JSON 覆盖数据库。

## 使用

- 白板上点“添加模块”，选模板并取名；空白模块可以用于阅读、学习等任意主题。
- 每个模块点“新增”添加一条记录，点击记录标题查看和编辑全文；点击模块标题会在顶部打开独立标签页。
- 模块右上角只保留“+”添加记录和“...”设置菜单；可设置属性、切换列表或表格、单独导出、收起到回收站。
- 支持文字、数字、日期属性；购物模板有金额、币种和商家，健康模板有时长。
- 计划可直接勾选。日记详情会显示关联的计划与健康记录。
- “数据与导出”中可以备份整个白板、导入备份或整理结果、撤销上次操作。
- 白板左上角提供添加模块、原始收件箱、番茄钟和主题设置四个独立入口。收件箱中已保存但尚未整理的条目可以重新编辑文字和附件。番茄钟支持自定义专注内容与 1–180 分钟时长，可暂停、继续或提前结束，并保留完成历史。

白板是可向任意方向平移的无边画布。拖动模块标题区域移动模块，位置保存到数据库；拖动空白处或用滚轮/触控板平移画布，Shift + 滚轮横移，Ctrl/Command + 滚轮缩放，Esc 回到初始视角。模块标题获得焦点后也可以用方向键移动，Shift + 方向键加大步长。

顶部标签栏始终保留“白板”入口。点击模块标题会把模块加入标签栏并打开专注视图；多个模块标签可以切换、关闭，刷新页面后仍保留。按 Esc 可从模块标签返回白板。

番茄钟支持倒计时和正计时，运行状态与历史记录会保存在数据库中。Linux/X11 下如果安装了 GTK3 Python 绑定和 Cairo，计时期间还会显示可拖动的置顶圆形浮窗，悬停可暂停、继续或结束。主题提供纯白、暖纸、雾灰和深夜四套完整配色，切换后也会保存在数据库中。数据与导出可以从添加模块窗口或模块设置菜单打开。当前不支持富文本嵌套、公式或 Notion 的全部功能。

## 隐私与初始数据

此公开仓库不包含作者的个人数据库、记录、附件或备份。首次启动时会在 `data/` 中创建一套空数据库。升级或迁移前请先在“数据与导出”中下载完整备份。

## 数据与迁移

完整数据保存于 `data/lifeos.sqlite`。模块定义、顺序、自定义属性、记录正文、原始收件箱、番茄钟历史和状态都在 SQLite 中；每次修改用事务提交。

`data/records.json` 和 `data/days/*.md` 是自动生成的可阅读副本，不是主存储，手工改动不会回写数据库。原始附件在 `data/attachments/`。

迁移优先使用应用导出的完整 ZIP，再导入另一个安装；也可以关闭应用后复制整个 data 文件夹。程序 ZIP 为便于移植，使用 JSON 快照随包携带资料，新安装首次运行时自动建立 SQLite。

更多说明见 [FORMAT.md](FORMAT.md)。

## AI 边界

网页输入和附件上传会直接保存，不会自行调用模型或识别小票。安装随附的 LifeOS 技能后，可在本机 Codex 的新对话里使用 `$lifeos` 或说“记到 LifeOS”，由当前对话模型整理，再通过本机接口批量保存。该流程不调用付费模型 API，但仍使用 Codex 的订阅额度。尚未提供云同步和自动提醒。

## 在新对话中记录

把 `skills/lifeos` 复制到当前用户的 Codex 技能目录（通常是 `~/.codex/skills/lifeos`），然后重启 Codex。例如：

> 使用 $lifeos：今天游泳 40 分钟，明天完成 Robotics Assignment 3。帮我记到白板。

技能保留日记原文，只提炼明确的运动、计划和购物，避免拆分琐事；会检查现有模块、按需新建模块、保存后核对结果。页面刷新后可看到新内容。新对话没有发现技能时，重启 Codex 再试。宿主对文件或本机服务的访问权限仍然适用。

`skills/lifeos/` 包含完整技能与标准库客户端：`context` 返回模块摘要，`context --date YYYY-MM-DD` 查询当天记录，`append --file batch.json` 批量新增，`upload --file receipt.png` 保存原始附件。服务未运行时会尝试启动已有应用，不会创建替代空库。

迁移时将技能复制到新电脑的用户技能目录，并修改其 `config.json`，让 `app_dir`、`data_dir` 指向迁移后的应用与资料目录。包内配置使用相对路径，可在原目录运行。此技能的本机连接不等同于 ChatGPT 手机端远程接入。
